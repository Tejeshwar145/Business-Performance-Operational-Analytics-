# Business Performance & Operational Analytics Dashboard

## About the Project

This project focuses on analyzing business data and presenting important findings through a Power BI dashboard. The main goal is to understand business performance, track key metrics, and identify trends that can help in making better decisions.

I worked with an Excel dataset, prepared the data for analysis, and used Power BI to create a dashboard that makes the information easier to understand.

## Project Objectives

* Clean and prepare the dataset for analysis.
* Analyze business data to understand trends and patterns.
* Calculate important business KPIs.
* Compare performance across different categories and time periods.
* Create an interactive dashboard using Power BI.
* Identify areas where business performance can be improved.

## Tools Used

* **Microsoft Excel** – Data storage and preparation
* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation

## Project Files

* `Business Performance & Operational Analytics Dashboard.pbix` – Power BI dashboard file.
* `Online_Retail_PowerBI_Final.xlsx` – Excel dataset used for the project.

## Project Workflow

### 1. Data Preparation

Reviewed the dataset and prepared the data for analysis. This involved checking data quality, handling inconsistencies, and organizing the data for reporting.

### 2. Data Analysis

Explored the available data to understand business performance, identify patterns, and compare different business segments.

### 3. KPI Analysis

Focused on important business metrics to make it easier to monitor performance and understand changes in the data.

### 4. Dashboard Development

Created a Power BI dashboard to present the analysis through charts, KPI cards, and other visualizations. The dashboard is intended to make the results easier to explore and interpret.

### 5. Insights

Used the analysis to identify trends and areas that may need further attention.

## Key Learnings

Through this project, I gained practical experience in preparing data, working with Power Query, analyzing business information, selecting suitable visualizations, and building a Power BI dashboard.

I also learned how to organize analytical findings in a way that makes them easier for others to understand.
